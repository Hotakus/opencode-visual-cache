# Security Policy

## Supported Versions

Security updates are provided for the latest published release on npm
([`opencode-visual-cache`](https://www.npmjs.com/package/opencode-visual-cache)).
Older releases are not maintained.

| Version | Supported |
| ------- | --------- |
| 1.6.x   | Yes       |
| < 1.6   | No        |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting instead:

- [Report a vulnerability](https://github.com/Hotakus/opencode-visual-cache/security/advisories/new)

Please include the affected version, a description of the issue, and a minimal
reproduction if possible.

You can expect an initial response within 7 days. Once a fix is available, a
patched release will be published to npm and a GitHub Security Advisory will be
published for the issue.
